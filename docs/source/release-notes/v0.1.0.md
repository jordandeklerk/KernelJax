# KernelJax 0.1.0 release notes

The first release of KernelJax, a low-level JAX library for nonparametric kernel smoothing
of mixed-type data.

## Highlights

- Every bandwidth selection criterion is an ordinary differentiable JAX function, so
  selection runs through a gradient based search rather than a derivative free one, and a
  bandwidth can be learned inside a larger model.
- The estimator family covers mixed samples end to end, from unconditional densities and
  regressions through conditional densities, distributions, quantiles, and modes.
- Every fit runs under `jit` on CPU, GPU, or TPU through XLA, with no change to the calling
  code.

## New features

### Estimators

- {func}`~kerneljax.density` and {func}`~kerneljax.cdf` estimate probability densities and
  cumulative distributions over samples mixing continuous, unordered, and ordered columns.
- {func}`~kerneljax.local_poly` fits local polynomial regressions at any degree, with
  gradients through `gradient=True` and pointwise standard errors through `se=True`.
- {func}`~kerneljax.cdensity` and {func}`~kerneljax.cdist` estimate conditional densities
  and conditional distribution functions given mixed covariates.
- {func}`~kerneljax.cquantile` inverts the conditional distribution for quantile regression,
  and {func}`~kerneljax.cmode` classifies through the conditional mode of a categorical
  response.
- {func}`~kerneljax.summary` reads any fit back and renders a goodness of fit report.

### Bandwidth selection

- {func}`~kerneljax.select_bandwidth` selects continuous bandwidths and categorical
  smoothing parameters jointly, with multiple restarts and a swappable solver.
- Likelihood, least squares, corrected AIC, and conditional criteria ship as configurable
  classes and as plain differentiable functions.
- {func}`~kerneljax.normal_reference` provides the closed form plug-in rule, and
  {func}`~kerneljax.lbfgs` is the default solver behind every search.
- Custom criteria are plain callables, documented end to end in
  [Custom bandwidth selection](../user-guide/custom-criteria.md).

### Kernels

- A second-order {class}`~kerneljax.Gaussian` for continuous columns,
  {class}`~kerneljax.AitchisonAitken` for unordered ones, and
  {class}`~kerneljax.WangVanRyzin` and {class}`~kerneljax.LiRacine` for ordered ones,
  collected through {class}`~kerneljax.KernelSet`.
- Custom kernels subclass one base class and implement one method, with numeric checks
  that verify mass and normalization when a feature first depends on them, documented in
  [Custom kernels](../user-guide/custom-kernels.md).

### Primitives

- {func}`~kerneljax.kweights` and {func}`~kerneljax.ksum` expose the kernel weight matrix
  and the contraction under every estimator, with a per column operator taking each column
  through its value, integral, derivative, or self convolution.
- {func}`~kerneljax.wls` and {func}`~kerneljax.hat_diagonal` expose the weighted least
  squares layer behind local polynomial regression.
- Every estimator accepts a `fold` array, so held out criteria never need a Python loop.

## Documentation

- A quickstart working one problem end to end, with every printed number
  produced by executing the page.
- Guides for [custom kernels](../user-guide/custom-kernels.md) and
  [custom bandwidth selection](../user-guide/custom-criteria.md) that build a working
  extension step by step.
- [Background](../background/smoothing.md) pages developing the statistical theory from
  first principles, and a design principles page explaining why
  the library is shaped the way it is.
