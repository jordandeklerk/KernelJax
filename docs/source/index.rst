KernelJAX
=========

**KernelJAX** is a low-level JAX library for nonparametric kernel smoothing of
mixed-type data, aimed at researchers who want to develop new methodology from
composable, differentiable building blocks. Written in JAX, it compiles to CPUs,
GPUs, and TPUs through XLA and supports automatic differentiation and
vectorization, so those pieces can be tailored, extended, and combined with other
libraries to fit a project's needs.

.. warning::

   KernelJAX is in early development. APIs are unstable and subject to change.

Installation
------------

.. code-block:: bash

   pip install kerneljax
