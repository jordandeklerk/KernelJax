# Contributing

These pages cover how a contribution travels from a fork to a merge, the conventions KernelJax code follows, how the documentation is built, and the infrastructure around both. Bug fixes, new estimators, documentation, and code review are all welcome. If you have a question or run into trouble, open an issue on [GitHub](https://github.com/jordandeklerk/KernelJax).
