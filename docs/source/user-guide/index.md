# User guide

The user guide develops KernelJax one topic per page, in reading order. It opens with what the library is and how a fit is read, works through each estimator family on a shared simulated wage example, and ends with the extension points for writing custom kernels and custom bandwidth selection. The [Background](../background/index.md) section develops the statistical theory these pages rely on, and the [API reference](../api.md) documents every exported object.
